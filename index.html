CGC ERP User Guide (Aasaan Bhasha Mein)

1. Login Kaise Karein?

Apna Employee Code small ya capital mein dalein (bina dash ke bhi chalega, jaise dg01 ya DG-01) aur 4-digit PIN daalkar login karein. Upar Key (🔑) icon se apna PIN kabhi bhi badal sakte hain.

2. Store Stock (Samaan Issue / Jama)

Kisi complaint ke liye samaan lene par item ke neeche "- Issue" dabayein, quantity aur ticket/site likhein. Samaan kam hone par WhatsApp alert button apne aap aayega.

3. Tool Crib (Grinder, Drill, Welding Set)

Subah tool le jaate waqt "Issue Tool" par click karke apna naam aur site dalein. Kaam khatam hone par "Mark Returned" zaroor dabayein.

4. DG Room / Boiler Meter Entry

"+ Meter Entry" mein Start HMR aur Stop HMR reading dalein. Run hours, average (Ltr/Hr), aur Main Diesel Tank ka bacha hua stock system khud calculate kar lega. Galti hone par entry ko Edit ya Delete bhi kar sakte hain.

5. Machine QR Scan & Gate Pass

Machine par lage QR sticker ko phone camera se scan karte hi uski service sheet khul jayegi. Campus se bahar repair ke liye motor bhejne par Gate Pass banayein aur WhatsApp par gate slip share karein.
